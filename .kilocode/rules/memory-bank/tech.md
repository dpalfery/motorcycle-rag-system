# Technology Stack

## Development Environment
- **Windows**: Default development environment
- **PowerShell**: Primary shell for CLI operations and scripting
- **Visual Studio 2022**: Primary IDE with .NET development tools

## Core Framework
- **.NET 9.0**: Latest .NET runtime with performance optimizations
- **ASP.NET Core**: Web API framework with minimal APIs
- **C# 12**: Modern language features and patterns

## AI & Machine Learning
- **Azure AI Foundry**: Unified platform for AI services
- **Azure OpenAI**: GPT-4o, GPT-4o-mini for text generation
- **text-embedding-3-large**: High-quality embeddings for search
- **Azure AI Search**: Hybrid vector/keyword search engine
- **Azure Document Intelligence**: OCR and document understanding
- **Semantic Kernel**: Agent orchestration and prompt engineering

## Cloud Infrastructure
- **Azure Container Apps**: Serverless container hosting
- **Azure App Configuration**: Centralized configuration management
- **Azure Key Vault**: Secure secret storage
- **Azure Application Insights**: Monitoring and telemetry
- **Azure Resource Manager**: Infrastructure management

## Development Tools
- **Visual Studio 2022**: Primary IDE
- **xUnit**: Unit testing framework
- **Moq**: Mocking library for tests
- **Swashbuckle**: Swagger/OpenAPI generation

## Deployment & DevOps
- **Pulumi**: Infrastructure-as-Code
- **Docker**: Containerization
- **GitHub Actions**: CI/CD pipelines
- **Azure CLI**: Cloud resource management

## Libraries & Patterns
- **Polly**: Resilience patterns (circuit breaker, retry)
- **Serilog**: Structured logging
- **FluentValidation**: Input validation
- **AutoMapper**: Object mapping
- **MediatR**: CQRS pattern implementation

## Architecture Patterns
- **Clean Architecture**: Layered separation of concerns
- **Dependency Injection**: Service lifetime management
- **Repository Pattern**: Data access abstraction
- **CQRS**: Command Query Responsibility Segregation
- **Observer Pattern**: Event-driven architecture
